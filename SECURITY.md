# Security Policy

## Supported Versions

There has not yet been an official production release. The only version currently supported with security updates is 1.0.x.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report any vulnerability by email to **security@atush.eu**. We will review your report and keep you informed of its status as soon as possible.

Please note that vulnerability reports generated by AI/LLM tools will not be prioritized.
